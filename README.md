# Playcademy-Take-Home-Assessment

A Svelte 5 + Vite base template with a default home page (lorem ipsum text, hero image, and three buttons that log to the console when clicked).

## Getting started

```bash
npm install
```

## Development

Start the dev server (defaults to http://localhost:5173):

```bash
npm run dev
```

## Build

Create a production build in `dist/`:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project structure

- `index.html` — Vite entry HTML
- `src/main.js` — mounts the Svelte app
- `src/App.svelte` — home page (lorem ipsum, hero image, button row)
- `src/app.css` — global styles
- `src/assets/hero.svg` — placeholder hero image
- `public/` — static assets served as-is
